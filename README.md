# IndiTribe Crafts

IndiTribe Crafts is a tribal artisan e-commerce platform that connects customers with traditional artisans and their handmade products.

The website allows customers to explore products, learn about artisans, add products to a cart, and complete a simulated checkout process.

## Features

- Browse handmade tribal products
- Search and filter products
- View product details
- Explore artisan profiles
- Product categories
- Customer registration and login
- Wishlist
- Shopping cart
- Simulated checkout
- Seller/artisan product submission
- Responsive design

## Tech Stack

- React
- TypeScript
- TanStack Start
- TanStack Router
- Tailwind CSS
- Supabase
- PostgreSQL
- React Hook Form
- Zod
